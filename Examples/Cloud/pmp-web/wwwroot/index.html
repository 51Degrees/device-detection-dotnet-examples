PMP web demo

Each page below carries the 51Degrees Preference Management Platform (PMP) and the 51Degrees client script in one of the arrangements a publisher could write, and nothing else apart from the small scripts the browser tests read. The platform asks the visitor how their data may be used, and the client script sends that answer to the cloud with everything else it has gathered, so the 51Did the cloud creates carries the answer. Open the browser console to see what each page says.

The same pages answer on any host name, so opening one page on two different names shows an answer being shared between two sites.

Pages that load everything from the cloud

  • Common path, the platform then the client script.
  • Common path, client script first, the same two tags the other way round.
  • Change of answer, with a handler on the client script's change event.
  • Two pages, an answer carried from one page to the next.
  • Consent platform only, a stand-in consent management platform and the client script.
  • No platform, the client script alone.
  • Platform with no client script, the platform alone.
  • Platform with a named object, the platform alone using another name for the client script's object.
